# A new project identity

Date: 2026-09-24. Status: shortlist only; no name selected or rename implemented.

## Direction

An opinionated Fedora + Hyprland workstation, configured as a cohesive personal
environment. Keep Omarchy's sense of ownership and deliberate defaults without
implying this is the official Fedora edition of that project.

## Five proposals

| Name | Idea and character | Tradeoff | .com lookup |
| --- | --- | --- | --- |
| **Fedarchy** | Fedora + anarchy; a clear sibling in spirit to Omarchy, with its own Fedora identity | Closest to the old name; less of a clean conceptual break | Reported available |
| **Hyprava** | Hyprland-inspired coined name; short, distinctive, and suitable for a desktop environment | Ties the identity to Hyprland; pronunciation needs settling | Reported available |
| **Ownora** | Ownership + a Fedora-like ending: your machine, your rules | Strong philosophy, but the exact domain is unavailable | Reported unavailable |
| **Werkora** | German “Werk” (work or creation) with a Fedora-like ending; a crafted developer workstation | German-English spelling may need explanation | Reported unavailable |
| **Taktora** | German “Takt” (rhythm) with a Fedora-like ending; a desktop built around personal workflow | More abstract; less immediately Linux-specific | Reported unavailable |

**Recommendation:** Fedarchy is the strongest fit for “the same direction as
Omarchy,” and its exact .com was reported available. Hyprava is the better choice
if a more independent identity matters most.

## Availability caveats

A batched lookup through `fly.urbanisierung.dev` checked the `.com`, `.io`, `.dev`,
and `.app` variants for these five names on the date above. The table records the
reported `.com` results, not a registration guarantee. Availability can change;
no domains were registered. Repository/package availability, existing product
usage, trademarks, and language screening have not been cleared.

Domain availability is not evidence that a name is legally or commercially free
to use. Recheck the selected name before adoption.

## Scope of a future rename

Selecting a name is not authorization for a global replacement. Installation
paths, command prefixes, configuration links, and update state require a migration
plan. See [Phase 7 of the action plan](action-plan.md#phase-7-adopt-a-new-identity-after-name-selection).
Preserve the existing MIT license and upstream attribution regardless of branding.
